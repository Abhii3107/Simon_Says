# 🎮 Simon Says

A fun and interactive memory game built with **HTML**, **CSS**, and **JavaScript** — inspired by the classic *Simon Says* game!

## 🧠 Overview

**Simon Says** challenges your memory by lighting up a sequence of colors that you have to repeat in the same order. With each level, the game gets harder by adding one more color to the sequence. How far can you go?

## 🚀 Features

- 🎨 Colorful and responsive design
- 🧩 Random sequence generation
- 🔊 Sound effects for better interactivity
- 📱 Works on mobile and desktop
- 🔁 Restart feature after a wrong attempt
